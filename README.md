# Supriya Maurya — UX/UI & Product Designer Portfolio

A personal portfolio website showcasing UX/UI design, product design, visual design, and frontend development work.

## Focus

- UX/UI and product design
- Design systems and responsive interfaces
- Dashboards, analytics, and B2B products
- AI-powered product experiences
- Frontend implementation with React

## Built With

- React
- JavaScript
- React Icons
- Swiper
- EmailJS

## Run Locally

```bash
git clone https://github.com/supriya224/react-portfollio.git
cd react-portfollio
npm install
npm start
```

Open http://localhost:3000.

## Production Build

```bash
npm run build
```
